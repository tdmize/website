Appendix 3F: Interpretation in y* Metric

  • The binary logit model can be interpreted in three ways:

    • y* metric
    • Odds ratios
      • Log odds
    • Predicted probabilities

  • The binary logit or probit model can be interpreted in terms of y*

    • This is uncommon in typical applications of the models
      • It is not the method I recommend/prefer
    • But useful to understand and used sometimes (e.g., in structural equation modeling [SEM])
    • Also, useful for ordinal logit/probit models (more later)

  • The coefficients can be directly interpreted in terms of y*. Remember the model is linear in the y* metric

    For a unit change in xk, y* is expected to change by βk units, holding all other variables constant

y* standardized interpretations

  • One solution is to y* standardize the coefficient; i.e. put it in standard deviation of y* units
  • First, need to calculate the variance/standard deviation of y*

\[\widehat{Var}(y^{*}) = \widehat{\boldsymbol{\beta}}' Var(\mathbf{x}) \widehat{\boldsymbol{\beta}} + Var(\varepsilon)\]

  • Where the variance of the error is assumed (1 in probit; π2/3 in logit)
  • Then, put coefficient in y* standard deviation units:

\[\beta_{k}^{Sy*} = \frac{\beta_{k}}{\sigma_{y*}}\]

For a unit increase in xk, y* is expected to increase by \(\boldsymbol{\beta_{k}^{Sy*}}\) standard deviations, holding all other variables constant

Advice on y* interpretations

  • y* interpretations only really make sense if you think an underlying latent continuum exists and you can name and talk about it cogently
  • Standardized coefficients are useful to facilitate comparisons across models: all are on the same standard deviation scale
    • If you are going to use y* interpretations, I recommend y* standardized coefficients
  • Ultimately, the interpretations are not very satisfying as the substantive magnitude of an effect is unclear—even with y* standardized coefficients
    • I find marginal effects a better default interpretation strategy (see 3.6 Marginal Effects)

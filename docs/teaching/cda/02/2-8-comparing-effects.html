2.8 Comparing Effects Across IVs

Research question: what social factors most strongly pattern political views?

  • Sometimes, want to compare effect sizes across predictors (IVs) within a model
    • Complicated by variables on different metric (e.g., age vs income), by variables of different types (e.g., binary vs continuous), and by nonlinearities of continuous IVs
  • For binary IVs, the 0 vs 1 effect already provides the full summary
  • For nominal IVs, can use an ME inequality
  • For continuous IVs, calculate marginal effects, even with nonlinearities
    • Can still provide an answer for the average effect
    • For comparing effect sizes across binary and continuous predictors, a +2 SD change is sometimes recommended (Gelman 2008) as comparable
    • More robust alternative is ME across trimmed range (5th to 95th percentile)
      • Logic: binary 0 vs 1 or ME inequality is entire range of variable’s effect; trimmed range similarly expresses entire range of continuous IV’s effect while protecting against outliers (Mize and Han 2025)

Comparing marginal effects within a model

  • In Stata, mecompare can simultaneously calculate multiple MEs, and then use metest for additional tests of equality
    • amount(trimrange) for 5th to 95th percentile change for continuous IVs
    • meinequality option for nominal IVs
  • In R, use avg_comparisons and specify each predictor of interest in a list( )
    • For a significance test of the difference in marginal effects, use the hypothesis option*
      • hypothesis = ~ pairwise will calculate all contrasts, but be careful with multiple exploratory hypothesis tests
  • To compare pure effect sizes and ignore direction, take the absolute value of the marginal effects before testing their equality

library(haven)           # import Stata data and labels
library(dplyr)           # data manipulation
library(marginaleffects) # predictions and marginal effects

source("https://raw.githubusercontent.com/tdmize/Rfunctions/main/ME_helper_functions.R")

gss <- read_dta("https://tdmize.github.io/data/data/cda_gss.dta")
gss <- gss |> filter(year == 2021)

# Keep only model vars and drop any missing data on them
gss <- gss[c("polviews", "age", "woman", "race4", "class")]
gss <- gss[complete.cases(gss), ]

# Treat binary/nominal variables as factors; drop categories with no cases
gss <- gss |> mutate(conpolviews = as.numeric(polviews), woman = as_factor(woman),
  race4 = as_factor(race4), class = as_factor(class)) |>
  droplevels()

mod42b <- lm(conpolviews ~ poly(age, 2, raw = TRUE) + woman + race4 + class, data = gss)

# Trimmed range of age: 5th to 95th percentile

# Effect sizes: ME of age, absolute ME of woman, ME inequality of race4 and class
effect_sizes <- function(x) {
  ineq <- meineq(mod42b)(x[x$term %in% c("race4", "class"), ])
  data.frame(term = c("age", "woman", ineq$term),
    estimate = c(x$estimate[x$term == "age"], abs(x$estimate[x$term == "woman"]),
      ineq$estimate))
}

sizes <- avg_comparisons(mod42b,
  variables = list(age = quantile(gss$age, c(.05, .95)), woman = "reference",
    race4 = "pairwise", class = "pairwise"),
  hypothesis = effect_sizes)

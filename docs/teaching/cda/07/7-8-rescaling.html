Intuitive explanation of rescaling

“The variance of Y* changes because estimation of the probability of success gets better and better as you add more variables, and better estimation in turn leads to more variability in the estimates. Suppose you had a single dichotomous independent variable… (gender)… All men would have the same predicted probability of success and all women would also share the same predicted probability. For example, men might have a 40% probability of success while women have a 50% chance.

As you add more variables, however, there will start to be more variability in the individuals’ predicted probabilities. So, among the men, after adding another variable the probabilities might now range between 35% and 45%, while for women the range might be 45%–55%. Hence, instead of the probabilities only ranging from 40% to 50%, adding another variable could cause the individual probabilities to range from 35% to 55%. If you are doing really well, adding more variables might even get you to the point where the predicted individual probabilities of success ranged from 0.0001 to 0.9999.”

Quote from Williams and Jorgensen 2023 p. 102802

Statistical explanation of rescaling: identification

  1. A logit/probit’s raw coefficients are in the metric of y*

\[y^{*} = \alpha + \mathbf{\beta x} + \varepsilon\]

  1. The size of y* is not independently identified and will vary across models
    • More explained variation \(\beta\) increases y*
    • The size of \(\varepsilon\) will reflect both:
      • The assumption about the distribution of the errors (ω: SD is 1 for probit; \(\pi/\sqrt{3}\) for logit)
      • Residual variation (\(\sigma_{\varepsilon}\))
        • The residual variation of the model changes with the inclusion / omission of different IVs
  2. Thus, logit/probit coefficients are said to be identified only “up to a scale factor”

\[b = \frac{\beta}{s} \qquad s = \frac{\sigma_{\varepsilon}}{\omega}\]

  1. Thus, the coefficients change in size across models, due not only to explained variation \(\beta\)

*See Williams and Jorgensen 2023 and Breen, Karlson, and Holm 2018 for excellent overviews of this issue

Solutions to the problem of rescaling: mediation

  • Consider the following where \(b_{yx}\) is the observed coefficient for focal IV x in model R (reduced model without mediator) and \(b_{yx \bullet z}\) is the observed coefficient for x in model F (full model with mediator z included)
    • \(\beta_{yx}\) and \(\beta_{yx \bullet z}\) are the true effects

\[b_{yx} - b_{yx \bullet z} = \frac{\beta_{yx}}{\sigma_{R}} - \frac{\beta_{yx \bullet z}}{\sigma_{F}} \neq \beta_{yx} - \beta_{yx \bullet z}\]

  • The difference \(b_{yx} - b_{yx \bullet z}\) does not equal \(\beta_{yx} - \beta_{yx \bullet z}\) because the scale parameters (σ) are not equal across models
    • If the additional variables in model F explain any variation in the outcome then \(\sigma_{R} > \sigma_{F}\) and thus \(b_{yx} - b_{yx \bullet z} \neq \beta_{yx} - \beta_{yx \bullet z}\)
  • Kohler, Karlson, Holm (2011) and Karlson, Holm, and Breen (2012) propose a solution (the KHB method) that uses a single scaling parameter across both models (equal to that of the full model)
  • The exact details of the KHB method are beyond the scope of this course—the key takeaway is that their solution allows the coefficients to be on the same scale so that they can be directly compared: significance tests from this method are appropriate tests of cross-model differences
    • Though the coefficient in the reduced model no longer has its natural interpretation
  • Because the coefficient from the reduced model is no longer directly interpretable, another way to represent the cross-model difference is the ratio of the two same-scale coefficients across models
    • Which can easily be represented as the proportion change in the size of the coefficient across the two models:

\[1 - \frac{\beta_{yx \bullet z}}{\beta_{yx}}\]

# R has no working built-in way to do the KHB method for logit models (the khb
# function in the matchingMarkets package fits probit models only), so calculate
# it by hand. The reduced model uses the part of the mediator (z) unrelated to the
# focal IV (x): its residual from a regression on x. Both models are then on the
# same scale, and the difference is the indirect effect.
khb_logit <- function(y, x, z, data) {
  aux <- lm(reformulate(x, z), data = data)              # z regressed on x
  data$z_res <- resid(aux)
  naive   <- glm(reformulate(x, y), data = data, family = binomial(link = "logit"))
  reduced <- glm(reformulate(c(x, "z_res"), y), data = data, family = binomial(link = "logit"))
  full    <- glm(reformulate(c(x, z), y), data = data, family = binomial(link = "logit"))

  b_red <- coef(reduced)[[x]]
  b_full <- coef(full)[[x]]
  est <- c(Reduced = b_red, Full = b_full, Diff = b_red - b_full)
  se <- c(sqrt(vcov(reduced)[x, x]), sqrt(vcov(full)[x, x]),
    # Diff = (coef of z in full model) * (coef of x on z); delta method
    sqrt(coef(aux)[[x]]^2 * vcov(full)[z, z] + coef(full)[[z]]^2 * vcov(aux)[x, x]))
  zval <- est / se
  print(round(cbind(Coef = est, "Std. Err." = se, z = zval, "P>|z|" = 2 * pnorm(-abs(zval)),
    "[95% Conf." = est - qnorm(.975) * se, "Interval]" = est + qnorm(.975) * se), 3))

  cat("\nSummary of confounding\n")
  round(c(Conf_ratio = b_red / b_full, Conf_Pct = 100 * (b_red - b_full) / b_red,
    Resc_Fact = b_red / coef(naive)[[x]]), 4)
}

Limitations of most methods for cross-model comparisons

  1. Coefficients are often not the effect of interest. The KHB method only tests mediation in the underlying linear y* metric
    • Marginal effects are often more informative; don’t want to switch between ME and y* metric for different parts of your analysis
  2. Many are limited to the special case of mediation
    • Even within these, multiple mediators are often not easily incorporated
  3. Effects that include multiple linked coefficients (e.g., age and age2) cannot be easily incorporated into existing frameworks that focus on the βs
  4. Some additional cross-model comparisons of interest that are difficult to test with current methods:
    • Test different specifications of an IV across models
    • Test effects across different DVs
    • Test differences across model types (e.g., ordinal vs multinomial logit)
    • Tests across different samples
      • E.g. Models fit separately across different groups
    • And more…

An alternative solution: predictions and MEs

  • An alternative to the methods that “fix” the coefficients to make them comparable is to instead work in the predictions and marginal effects

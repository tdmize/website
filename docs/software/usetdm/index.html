usetdm

Stata command to download example data for classes, workshops, and replication files

usetdm loads datasets from the web to recreate the examples from various classes and workshops, and the replication files from various projects. The datasets live in the data/ folder of the tdmize/data GitHub repository; usetdm saves typing the address. Every dataset on this page can also be opened without installing anything:

use "https://tdmize.github.io/data/data/gss", clear

Installation

net install usetdm, from("https://tdmize.github.io/data") replace

Use

usetdm dataname [, clear]

Option clear must be specified if another dataset is currently in memory.

usetdm gss, clear

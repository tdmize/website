irt_coef

Stata command for y*-standardized coefficients in item response theory models

irt_coef is a Stata command that calculates y*-standardized coefficients for binary and ordinal item response theory (IRT) models. The discrimination parameters of an IRT model are on the log-odds (or probit) scale of each item, which makes their size hard to judge; standardizing on the latent propensity y* behind each item puts the coefficients on a common scale for interpreting them and for comparing across items and models. The raw coefficient, its standard error, and p-value are reported alongside the standardized coefficient.

Both types of coefficients are covered in my graduate course slides on item response theory: Item Response Theory slides. All of the materials for the course, including example code, are on the Latent Variable Modeling page.

Installation

net install irt_coef, from("https://tdmize.github.io/data") replace

To read the help file in Stata, type help irt_coef; it is also on this site.

Citation

Please cite the use of irt_coef as:

Mize, Trenton D. 2024. “irt_coef: Stata command for y*-standardized coefficients in item response theory models.” https://www.trentonmize.com/software/irt_coef

Examples

After the irt command

The example fits a graded response model to ten ordinal items measuring mastery (a sense of control over one’s life) in Add Health Wave IV.

use "https://tdmize.github.io/data/data/lvm_ah4", clear
(Add Health Wave IV | Latent Variable Modeling Class | )

After gsem

An identical model can be fit with gsem. Because gsem lets the latent variable take any name, the latent() option tells irt_coef which one to use (after irt it is always Theta, and the option is not needed).

                 othersdetR interfereR lowcontrolR cantsolveR, ologit), var(Mastery@1)

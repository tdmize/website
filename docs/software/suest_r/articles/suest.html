Getting started with suest

suest() combines two or more separately fitted models so you can test whether predictions, marginal effects, or other quantities differ across the models. It supplies the joint robust covariance matrix those tests need, and leaves calculating and presenting the quantities themselves to marginaleffects.

Functions at a glance

  • suest() combines two or more fitted models and calculates their joint covariance matrix.
  • suest_newdata() stacks the models’ estimation samples so each model’s effects can be averaged over its own sample.
  • suest_mi() pools suest() results across multiply imputed datasets.
  • The usual marginaleffects functions, including predictions(), avg_comparisons(), avg_slopes(), hypotheses(), and the plotting functions, work with the combined object.

Installation and setup

remotes::install_github("tdmize/suest")
library(suest)
library(marginaleffects)

combined <- suest(base, adjusted, model_names = c("Base", "Adjusted"))

Combining models

Models can use the same, partially overlapping, or completely different samples. Any single-level models can be combined, including models for different outcomes and models for categorical outcomes. Results on different scales are labeled separately rather than treated as directly comparable. Panel and multilevel models can be combined only with models of the same kind, such as two random-intercept logit models, and must be unweighted. Offsets are supported, except in pglm() and glmmTMB() models.

A few models have settings worth knowing about; see Notes on specific models.

Different samples or groups

When the models are fitted to different samples, such as separate groups, use suest_newdata() so each model’s effects are averaged over its own sample:

four <- lm(mpg ~ wt + hp, data = mtcars, subset = cyl == 4)
other <- lm(mpg ~ wt + hp, data = mtcars, subset = cyl != 4)
fit_groups <- suest(four, other, model_names = c("Four cylinders", "Other"))

effects_groups <- avg_comparisons(fit_groups, variables = "wt",
                                  newdata = suest_newdata(fit_groups))

Cluster-robust standard errors

Supply a cluster variable to get cluster-robust standard errors for the combined models:

fit_clustered <- suest(base, adjusted, cluster = "person_id")
avg_comparisons(fit_clustered, variables = "x", newdata = dat)

cluster takes one or more column names, or a list with one vector, matrix, or data frame matched to each model’s estimation sample. An observation that appears in more than one model must have the same cluster ID in each. Observations in completely different samples can belong to the same cluster, in which case the covariance between models can be nonzero.

Panel models cluster on the panel identifier by default. A cluster you supply must contain whole panels.

Probability weights

suest supports probability weights for linear, binary logit and probit, Poisson, negative binomial, ordered logit and probit, and multinomial logit models. Fit each model with weights=, and tell suest() that they are probability weights with weight_type = "pweight":

set.seed(376)
weighted <- data.frame(x = rnorm(500), z = rnorm(500))
weighted$mediator <- 0.5 * weighted$x - 0.3 * weighted$z + rnorm(500)
weighted$pw <- exp(0.2 * weighted$z + 0.1 * rnorm(500))
weighted$y <- 1 + 0.7 * weighted$x - 0.4 * weighted$z +
  0.6 * weighted$mediator + rnorm(500)

base_w <- lm(y ~ x + z, weights = pw, data = weighted)
adjusted_w <- lm(y ~ x + z + mediator, weights = pw, data = weighted)
fit_w <- suest(base_w, adjusted_w, model_names = c("Base", "Adjusted"),
               weight_type = "pweight")

Weights must be positive and finite. An observation that appears in more than one model must have the same weight in each; weights can differ for observations in only one model, including completely different samples. When the models have different estimation samples, suest_newdata() includes the weights as .suest_weight:

nd_w <- suest_newdata(fit_w)
avg_comparisons(fit_w, variables = "x", newdata = nd_w, wts = ".suest_weight")

Survey data

suest supports linear and binary logit or probit models fitted with survey::svyglm() from one common one-stage survey design:

library(survey)
design <- svydesign(~psu, strata = ~strata, weights = ~w, data = dat)
m1 <- svyglm(yb ~ x, design, family = quasibinomial("logit"))
m2 <- svyglm(yb ~ x + z, design, family = quasibinomial("logit"))
fit <- suest(m1, m2, survey_design = design, observation_id = "id")
avg_slopes(fit, variables = "x", newdata = suest_newdata(fit), wts = ".suest_weight")

If either model uses a subset (domain) of the data, keep design as the full sampled design. The joint covariance accounts for strata, PSUs, and optional one-stage finite population corrections. Linear and binary models can’t be mixed in the same system. Replicate weights, multistage designs, calibration, and PPS designs are not supported.

Multiple imputation

To combine results across imputed datasets, fit the same suest system in each one and pool them with suest_mi(). Results from mice::with() can be pooled directly:

analyses <- with(imp, suest(
  lm(y ~ x),
  lm(y ~ x + z),
  model_names = c("Base", "Adjusted")
))
pooled <- suest_mi(analyses)
summary(pooled)

A list of suest() results, one per imputation, or the result of with(mitools::imputationList(...), suest(...)) can also be passed to suest_mi().

suest_mi() applies Rubin’s rules to the full set of coefficients, keeping the covariance between models both within and between imputations. Tests of coefficients work through marginaleffects::hypotheses(). Predictions, slopes, and comparisons are not yet available for pooled results.

Two-part models

A two-part model is used when an outcome is the product of a mix of two processes, one for observed zeroes and non-zeroes, and one for an amount among the non-zeroes. The expected outcome is the product of the two:

\[E(y) = \Pr(y > 0) \times E(y \mid y > 0)\]

In R, fit the two parts as separate models and combine them with suest() and the twopart option. Predictions and marginal effects from marginaleffects are then on the expected outcome, with standard errors from the joint covariance of the two parts.

The examples use the medical expenditures of 19,386 adults in the 2004 Medical Expenditure Panel Survey. The first part is a logit of whether a person had any medical expenditures. The second part is a Poisson model of expenditures among the people who had any. With the robust standard errors suest() computes, this is Poisson pseudo-maximum likelihood: it fits a model of the mean of any outcome that is zero or positive, not only counts, and needs only the model of the mean to be right (Santos Silva and Tenreyro 2006). family = quasipoisson fits it without warnings about outcomes that are not whole numbers.

Fit the two parts and combine them

Both parts cluster on the dwelling unit (duid):

library(suest)
library(marginaleffects)
library(haven)

meps <- zap_labels(read_dta("https://tdmize.github.io/data/data/meps.dta"))
meps[c("female", "ins_unins", "anylim")] <-
  lapply(meps[c("female", "ins_unins", "anylim")], factor)
table(meps$exp_tot > 0)

amount <- glm(exp_tot ~ age + female + lninc + pcs12 + mcs12 + ins_unins +
                anylim, family = quasipoisson, data = meps, subset = exp_tot > 0)

fit <- suest(any, amount, model_names = c("Any", "Amount"), cluster = "duid",
             twopart = TRUE)

With survey data, put the weights and clusters in a svydesign(), fit the first part to the full design and the second part to the people with any expenditures, and give suest() the full design. wts = TRUE averages with the sampling weights:

design <- survey::svydesign(ids = ~duid, weights = ~wtdper, data = meps)
any_s <- survey::svyglm(I(exp_tot > 0) ~ age + female + lninc + pcs12 + mcs12 +
                          ins_unins + anylim, design = design,
                        family = quasibinomial)
amount_s <- survey::svyglm(exp_tot ~ age + female + lninc + pcs12 + mcs12 +
                             ins_unins + anylim,
                           design = subset(design, exp_tot > 0),
                           family = quasipoisson)
fit_s <- suest(any_s, amount_s, survey_design = design,
               observation_id = "dupersid", twopart = TRUE)
avg_slopes(fit_s, variables = c("age", "ins_unins"), wts = TRUE)

This describes the people who spend, but it is averaged over different observations than the first part’s effect, so the two can differ partly because the observations used to calculate the marginal effect differ.

How well the model predicts

The correlation between the outcome and its expected value summarizes how well a two-part model predicts. It depends only on the expected outcome, so it applies with any second part:

p <- predictions(fit)
cor(p$exp_tot, p$estimate)
[1] 0.3916091

The correlation is .392.

Other second parts

The second part can also be a Gamma model with a log link (glm(family = Gamma(link = "log"))), a linear model (lm()), or a negative binomial model (MASS::glm.nb()); twopart works the same way with each. With a linear model of the log of the outcome, add retransform = "duan" for Duan’s (1983) smearing estimate or retransform = "normal" for the normal-theory retransformation:

meps$ln_exp <- ifelse(meps$exp_tot > 0, log(meps$exp_tot), NA)
ln_amount <- lm(ln_exp ~ age + female + lninc + pcs12 + mcs12 + ins_unins +
                  anylim, data = meps, subset = exp_tot > 0)
fit_ln <- suest(any, ln_amount, model_names = c("Any", "LnAmount"),
                cluster = "duid", twopart = TRUE, retransform = "duan")
avg_slopes(fit_ln, variables = c("age", "ins_unins"))

Comparing two-part models

This example compares two second parts: a Gamma model with a log link, and Poisson pseudo-maximum likelihood. Both share the first part, a logit of whether a person had any expenditures. twopart names the two pairs, each a first part and its second part; Any is in both:

any <- glm(I(exp_tot > 0) ~ age + female + lninc + ins_unins,
           family = binomial, data = meps)
gamma <- glm(exp_tot ~ age + female + lninc + ins_unins,
             family = Gamma(link = "log"), data = meps, subset = exp_tot > 0)
poisson <- glm(exp_tot ~ age + female + lninc + ins_unins,
               family = quasipoisson, data = meps, subset = exp_tot > 0)

fit2 <- suest(any, gamma, poisson, model_names = c("Any", "Gamma", "Poisson"),
              twopart = c("Any", "Gamma", "Any", "Poisson"))
effects2 <- avg_comparisons(fit2, variables = c("ins_unins", "age"))

The two models give nearly the same effect of being uninsured: expected expenditures about $2,840 lower. The difference between them, about $4, is not significant. The effect of a year of age is about $108 with the Gamma second part and $100 with the Poisson one, and that difference, about $8, is significant.

A two-part model can also be compared with a single model for the outcome. Models not named in twopart keep their own prediction – here, a Poisson model fit to everyone, zeros included:

one_part <- glm(exp_tot ~ age + female + lninc + ins_unins,
                family = quasipoisson, data = meps)

fit3 <- suest(any, poisson, one_part, model_names = c("Any", "Poisson", "OnePart"),
              twopart = c("Any", "Poisson"))
effects3 <- avg_comparisons(fit3, variables = c("ins_unins", "age"))

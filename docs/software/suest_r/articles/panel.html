Panel models

Random-effects logits

A 30% sample of households from the Health and Retirement Study, 2010 to 2020 (the households whose ID ends in 0, 1, or 2): about 31,500 interviews of 7,800 people aged 51 and older, interviewed every two years. The two outcomes are depressive symptoms (four or more of the eight CES-D items) and fair or poor self-rated health. Each is a random-intercept logit fit with 25-point adaptive quadrature, with age centered at 65.

library(suest)
library(marginaleffects)
library(haven)
library(lme4)

hrs <- zap_labels(read_dta("https://tdmize.github.io/data/data/hrs_si_2025.dta"))
hrs <- subset(hrs, year >= 2010 & age >= 51 & (hhidpn %/% 1000) %% 10 < 3)
hrs$depressed <- as.numeric(hrs$cesd >= 4)
hrs$poorhealth <- as.numeric(hrs$srhealthB == 0)
vars <- c("depressed", "poorhealth", "marstatB", "age", "woman", "race4cat", "collegeB")
hrs <- hrs[complete.cases(hrs[vars]), ]
hrs[c("marstatB", "woman", "race4cat", "collegeB")] <-
  lapply(hrs[c("marstatB", "woman", "race4cat", "collegeB")], factor)

dep <- glmer(depressed ~ marstatB + I(age - 65) + woman + race4cat + collegeB +
               (1 | hhidpn), family = binomial, data = hrs, nAGQ = 25,
             control = glmerControl(optimizer = "bobyqa"))
health <- glmer(poorhealth ~ marstatB + I(age - 65) + woman + race4cat + collegeB +
                  (1 | hhidpn), family = binomial, data = hrs, nAGQ = 25,
                control = glmerControl(optimizer = "bobyqa"))
fit_re <- suest(dep, health, model_names = c("Depressed", "Poor health"))

suest() clusters the standard errors on the person. The marginal effects average over the random intercept, so they are changes in the probability of each outcome; age is changed by ten years:

effects_re <- avg_comparisons(fit_re,
  variables = list(marstatB = "reference", age = 10, woman = "reference",
                   race4cat = "reference", collegeB = "reference"),
  newdata = hrs)

Example interpretation: Being married is associated with a larger reduction in the probability of depressive symptoms (9.6 percentage points) than in the probability of fair or poor health (6.9 points); the difference of 2.7 points has \(p < .001\). Ten more years of age are associated with a 1.3 point reduction in depressive symptoms but a 3.4 point increase in fair or poor health.

A random-effects model mixes differences between people with changes within a person. The within-person effects example separates them.

Fixed-effects models

The National Longitudinal Survey of Young Women, 1968 to 1988: log wages and hours worked, each regressed on total work experience, union membership, their interaction, and year, with a fixed effect for each woman.

library(plm)

nlswork <- zap_labels(read_dta("https://tdmize.github.io/data/data/nlswork.dta"))
nlswork[c("union", "year")] <- lapply(nlswork[c("union", "year")], factor)

wage_fe <- plm(ln_wage ~ ttl_exp * union + year, data = nlswork,
               index = c("idcode", "year"), model = "within")
hours_fe <- plm(hours ~ ttl_exp * union + year, data = nlswork,
                index = c("idcode", "year"), model = "within")
fit_fe <- suest(wage_fe, hours_fe, model_names = c("Log wage", "Hours"))

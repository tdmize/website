Notes on specific models

Most supported models need nothing special. The notes below cover the few that do. Fits that suest can’t use, such as penalized fits or models that did not converge, stop with an error that explains why.

Linear models

Linear models add an lnvar parameter (the log of the error variance) to the combined coefficients and covariance matrix. It has no effect on predictions or marginal effects.

Linear panel models

For plm::plm() models, comparisons of slopes and changes are supported. Confidence intervals and tests for average predicted levels at the estimation-sample means are not: their standard errors can be missing or near zero.

Constant-dispersion negative binomial

  • Stata’s nbreg, dispersion(constant) is glmmTMB(y ~ x, family = nbinom1()), and menbreg, dispersion(constant) adds random effects, as in glmmTMB(y ~ x + (1 | id), family = nbinom1()). The conditional variance is mu*(1 + exp(log_phi)), and log_phi is Stata’s /lndelta.
  • Stata’s default nbreg (mean dispersion) is MASS::glm.nb(), or glmmTMB(family = nbinom2()) with random effects.

Population-averaged (GEE) models

  • geeglm() models can use independence, exchangeable, ar1, or unstructured working correlations. As in Stata, suest holds the working correlation at its estimate.
  • geepack and Stata estimate unstructured correlations the same way, so their results match. They estimate ar1 correlations differently, so ar1 coefficients and standard errors differ slightly. To reproduce R’s ar1 results in Stata, use corr(fixed R) (for example xtlogit y x, pa corr(fixed R)), where R has entries alpha^|j - k| and alpha is model$geese$alpha.
  • For ar1, give geeglm() the time variable, waves = time, so the correlation depends on the time between observations; without it, geepack uses each observation’s position in its panel. Stata leaves out panels whose times are unequally spaced unless you add force, which then uses the order of the observations.
  • Unstructured correlations need each panel’s waves to run 1, 2, …; panels can end early but cannot skip a wave. geepack cannot fit unstructured correlations with skipped waves (R stops with a memory error), although Stata can.

Parametric survival models

  • Predictions from survreg() and svysurvreg() models of survival time (Weibull, exponential, lognormal, log-logistic) are median survival times, as after streg. predict(type = "response") instead gives exp(linear predictor), which is the median for lognormal and log-logistic models but not for Weibull and exponential ones.
  • Stata’s log likelihood after streg leaves out the sum of log times over the failures, so it is higher than survreg’s and flexsurv’s by that amount. Estimates and standard errors are the same.

Gompertz and generalized gamma survival

  • Stata’s streg, distribution(gompertz) is flexsurvreg(Surv(time, event) ~ x, dist = "gompertz"), and streg, distribution(ggamma) is dist = "gengamma". Stata’s ancillary() and anc2() are flexsurv’s anc, as in anc = list(shape = ~ z) for the Gompertz gamma or anc = list(sigma = ~ z, Q = ~ z) for the generalized gamma.
  • Delayed entry, stset time, failure(event) enter(time entry), is Surv(entry, time, event).
  • Predictions are median survival times, as after streg.
  • flexsurv’s optimizer can stop slightly short of the maximum, so estimates can differ from Stata’s in the fourth or fifth decimal place (up to about 1e-4 for a generalized gamma coefficient with flexsurv’s default settings).

Bivariate probit

  • Stata’s biprobit (y1 = x z) (y2 = x w) is gjrm(list(y1 ~ x + z, y2 ~ x + w), margins = c("probit", "probit"), model = "B", data = d). Predictions are the probability that both outcomes equal 1, as after biprobit.
  • GJRM approximates the bivariate normal probabilities closely but not exactly, so its estimates can differ from Stata’s by about 1e-7.

Generalized ordered models

  • VGAM::vglm() with cumulative(link = ..., reverse = TRUE) is gologit2 with the logit, probit, cloglog, or cauchit link ("logitlink", "probitlink", "clogloglink", "cauchitlink"). parallel = TRUE is gologit2, pl, and parallel = FALSE ~ x frees x only, as in gologit2, npl(x).
  • gologit2’s link(loglog) is cumulative(link = "clogloglink", reverse = FALSE): the same model, with every coefficient’s sign reversed.

Zero-inflated models

When every model in the system is a pscl::zeroinfl() model (Poisson or negative binomial), predictions and marginal effects take the same type values as zeroinfl:

type Prediction Stata margins after zip or zinb
"response" (the default) Expected count predict(n)
"count" Mean of the count part expression(exp(predict(equation(depvar))))
"zero" Probability of a structural zero predict(pr)
"prob" Pr(y = k) for k = 0 to the largest observed count predict(pr(k))

Here depvar is the name of the count outcome, which names the count equation. With type = "prob", each count is a separate outcome, labeled model::0, model::1, and so on. Negative-binomial probabilities depend on the dispersion parameter, and their standard errors include its uncertainty. Standard errors use the exact observed information, as Stata does.

library(suest)
library(marginaleffects)
data("bioChemists", package = "pscl")

zip <- pscl::zeroinfl(art ~ fem + kid5 + ment | ment, data = bioChemists)
zinb <- pscl::zeroinfl(art ~ fem + kid5 + ment | ment, data = bioChemists,
                       dist = "negbin")
zi_fit <- suest(zip, zinb, model_names = c("ZIP", "ZINB"))

# Effect of mentor productivity on the probability of a structural zero,
# and its difference across the two models
avg_slopes(zi_fit, variables = "ment", type = "zero")

Mixed models fitted with glmmTMB

  • Predictions and marginal effects average over the random intercept, and over the random slope when there is one.
  • Center continuous predictors and keep them in well-scaled units. glmmTMB’s covariance matrix can be inaccurate with extreme predictor units even when the model reports convergence, and suest uses that covariance as supplied.
  • For slopes of continuous predictors in logit random-slope models, use numderiv = list("fdcenter", eps = 1e-4) in avg_slopes() for more stable standard errors, and check that nearby step sizes (such as 5e-5 and 2e-4) give similar answers.

Several random slopes and three-level models

  • lmer(), glmer(), glmmTMB(), and clmm() models can have several random slopes for the grouping variable, (1 + x1 + x2 | school), and one level nested in it, (1 + x1 | school) + (1 | school:class) or (1 | school/class). In Stata, these are || school: x1 x2, covariance(unstructured) || class:. Independent terms, (1 + x1 || school), and glmmTMB’s diag() are Stata’s covariance(independent). Crossed random effects and a third grouping level are not supported.
  • Slopes must be numeric data columns. Make a numeric 0/1 version of a factor, and create transformed variables (such as squares) before fitting.
  • The variance parameters are each term’s log standard deviations, log_sd_school_x1, and Fisher z correlations, atanh_rho_school_intercept_x1, as in Stata’s lns and atr. A nested level is named with a dot: log_sd_school.class_intercept.
  • Nonlinear models with these structures use the Laplace approximation (lme4 allows adaptive quadrature only for a single random intercept), while suest2 requires adaptive quadrature. Stata’s me commands with intmethod(laplace) give the same estimates and log likelihood, but the standard errors they report for these fits can differ from the exact Laplace standard errors by a few percent. Linear models agree with mixed exactly.
  • Fits near a boundary, with a variance near zero or correlations near -1 or 1, are refused even when lme4 does not flag them as singular. Simplify the random-effects structure.

Survey models

  • Binary probit and cloglog (svyglm()), ordered (svyolr()), multinomial, negative-binomial, and generalized ordered (svy_vglm()), and survival (svysurvreg()) models use exact observed information, as Stata does. Their standard errors can differ from the fitted model’s own: svyglm() and VGAM use expected information, svyolr() uses a numerical Hessian, and for interval-censored outcomes survival’s scale residuals are incorrect.
  • These fits stop at fairly loose tolerances. For results that agree closely with Stata, tighten them: control = list(reltol = 1e-12) in svyolr() and control = VGAM::vglm.control(criterion = "coefficients", epsilon = 1e-9) in svy_vglm().
  • svy_vglm() multinomial models use the last category as the reference unless multinomial(refLevel = ) says otherwise.
  • suest() finds an svyivreg() model’s design from its call, so keep that design object available.

Stata models without an R version

For these Stata models, suest supports a model that answers the same question. The last column fits the same model in Stata.

Stata model Use in R Same model in Stata
xtlogit, fe Random-intercept logit with each time-varying predictor’s person mean added (glmer(), glmmTMB(), or pglm()); see Within-person effects xtlogit, re or melogit with the person means
xtmlogit, fe nnet::multinom() with the person means, clustered on person mlogit with the person means, vce(cluster id)
xtmlogit, re nnet::multinom() clustered on person mlogit, vce(cluster id)
xtnbreg, fe Fixed-effects Poisson, fixest::fepois() xtpoisson, fe
xtnbreg, re Random-intercept negative binomial, glmmTMB() menbreg
xtnbreg, pa Population-averaged Poisson, geepack::geeglm() xtpoisson, pa vce(robust)
mestreg survreg() clustered on the group streg, vce(cluster group)

Fixed-effects Poisson with robust standard errors is valid for overdispersed counts, and xtnbreg, fe is not a true fixed-effects model (Allison and Waterman 2002). The multinomial and survival stand-ins have no random effects, so they estimate effects averaged over people rather than for a given person.

Allison, P. D., & Waterman, R. P. (2002). Fixed-effects negative binomial regression models. Sociological Methodology, 32, 247-265.

Models fitted with different packages

Models fitted by different packages can be combined, as long as they are supported models.

library(suest)
library(marginaleffects)

glm() and glm2::glm2():

library(glm2)

dat <- mtcars
dat$am <- factor(dat$am)

standard <- glm(am ~ wt + hp, family = binomial("logit"), data = dat)
alternative <- glm2(am ~ wt + hp, family = binomial("logit"), data = dat)
engine_fit <- suest(standard, alternative, model_names = c("glm", "glm2"))
avg_comparisons(engine_fit, variables = "wt", newdata = dat)

ordinal::clm() and MASS::polr(). clm() models need flexible thresholds and no scale or nominal-effects formula.

library(ordinal)

housing <- MASS::housing[rep(seq_len(nrow(MASS::housing)), MASS::housing$Freq),
                         c("Sat", "Infl", "Type", "Cont")]
rownames(housing) <- NULL
housing$Sat <- ordered(housing$Sat, levels = c("Low", "Medium", "High"))

clm_model <- clm(Sat ~ Cont + Infl + Type, data = housing, link = "logit")
polr_model <- MASS::polr(Sat ~ Cont + Infl + Type, data = housing,
                         method = "logistic", Hess = TRUE)
ordinal_fit <- suest(clm_model, polr_model, model_names = c("clm", "polr"))
avg_comparisons(ordinal_fit, variables = "Cont", newdata = housing)

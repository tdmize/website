Examples from the help file

The examples at the end of help mecompare, run in full

These are the examples from the end of the help file, in the same order, with their output. They use Stata’s nlsw88 data; every line can be pasted into Stata as is.

Fit and store the models, then compare marginal effects

Factor syntax is required for the regression models; it is optional for mecompare.

sysuse nlsw88, clear
